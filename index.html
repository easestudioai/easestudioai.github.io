EaseStudio Automation is a private, owner-operated set of workflows, including n8n integrations and AffiAuto. AffiAuto prepares affiliate video packages and uploads their MP4 and JSON files directly to the owner's selected Google Drive folders. It reads back each uploaded file to check that the content is complete.

Google Drive access is used only for those owner-directed file operations and their verification. This site explains the OAuth consent shown when the owner connects their Google account.
